# Results

- `userspace/current.md`: userspace proof snapshot and current compact
  runtime/update/memory evidence.
- `native/current.md`: current Linux overlay and kernel-backed compact
  measurement state.
- `native/README.md`: runtime kernel measurement matrix to fill from a kernel
  carrying the map type and kfunc prototype.

The repository keeps result entrypoints stable. Date-stamped working notes and
raw scratch logs are intentionally folded into `current.md` files or `SPEC.md`
instead of being retained as parallel sources of truth.
