## Notes

The previous kernel snapshot had byte-trie matched decisions around
352-356 ns/op and LPM around 241-291 ns/op. With runtime-only chain
compression, the matched io_graph path drops to 156-170 ns/op in this WSL run
and now beats the same raw-tracepoint LPM baseline for these policy shapes.

The compact prefilter DROP row reports zero POST hits and returns before
ringbuf reserve. Rejected events are therefore 0 ringbuf bytes in this bench
path. POST-side payload-copy rows still need a separate kernel bench mode.

This run does not provide p95/p99/p999 per-event latency or PMU counters. The
Linux selftests bench reports one-second throughput samples plus mean/stdev;
native PMU-visible validation is still needed for branch/cache counters.
